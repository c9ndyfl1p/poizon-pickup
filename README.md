# POIZON PICKUP

Локальный MVP Telegram Mini App для расчёта выкупа и сохранения заявок.

## Запуск в Docker

1. Установите и запустите Docker Desktop.
2. При первой настройке скопируйте шаблон настроек; если `.env` уже создан, редактируйте его и не заменяйте шаблоном — в нём хранится токен бота:

   ```sh
   test -f .env || cp .env.example .env
   # Укажите актуальный курс Pronto в .env перед использованием для заказов.
   PATH="/Applications/Docker.app/Contents/Resources/bin:$PATH" docker compose up --build
   ```

3. Откройте [http://localhost:8000](http://localhost:8000). Локальный просмотр работает без бота; такие заявки сохраняются без Telegram ID.
4. Панель заявок: [http://localhost:8000/admin](http://localhost:8000/admin), логин `admin`, пароль берётся из `.env` (`local-demo-only` только для локального просмотра).

SQLite-файл хранится в `./data/orders.sqlite3` и переживает перезапуск контейнера.

## Подключение Telegram Mini App

1. Создайте бота через BotFather и добавьте его токен в `BOT_TOKEN` в `.env`.
2. Укажите публичный HTTPS-адрес этого приложения в настройке Mini App у BotFather. Для локального тестирования потребуется HTTPS-туннель.
3. Открывайте приложение кнопкой бота. При первом открытии клиентский код отправляет `Telegram.WebApp.initData`; сервер проверяет подпись токеном бота и автоматически записывает Telegram ID в таблицу `users`, даже до оформления заказа.
4. При следующем запуске тот же Telegram ID узнаётся автоматически. На первых двух заказах применяется комиссия нового клиента, начиная с третьего — постоянного. Веб-запросы без проверенного `initData` не могут указать произвольный Telegram ID.

Бот не обязан передавать ID отдельным запросом: Mini App получает подписанные данные пользователя от Telegram. Уведомления менеджеру и платежи пока не подключены.

## Расчёт

- Цена товара умножается на `PRONTO_RATE + 0.25 ₽`.
- Комиссия равна проценту от рублёвой стоимости товара, но не ниже минимума для категории/статуса.
- На первых двух заказах применяется тариф нового клиента; с третьего заказа — тариф постоянного клиента.
- Доставка не входит в предоплату и определяется после взвешивания в Китае.
- Если `PRONTO_RATE` не задан, калькулятор показывает пример курса 13,55 ₽ + буфер и явно помечает его как пример. Перед использованием для реальных заказов внесите текущий курс Pronto в `.env`.
- Для обновления курса измените `PRONTO_RATE` в `.env` и перезапустите контейнер (`PATH="/Applications/Docker.app/Contents/Resources/bin:$PATH" docker compose up -d`). В приложении хранится курс Pronto без буфера; экран показывает курс выкупа с добавленными 0,25 ₽.

## Переменные окружения

См. `.env.example`. Перед доступом из интернета замените пароль администратора и используйте HTTPS. Доступ к панели `/admin` защищён HTTP Basic Auth.
