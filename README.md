# POIZON PICKUP

Локальный MVP Telegram Mini App для расчёта выкупа и сохранения заявок.

## Запуск в Docker

1. Установите и запустите Docker Desktop.
2. При первой настройке скопируйте шаблон настроек; если `.env` уже создан, редактируйте его и не заменяйте шаблоном — в нём хранится токен бота:

   ```sh
   test -f .env || cp .env.example .env
   # Задайте уникальный ADMIN_PASSWORD перед первым запуском.
   PATH="/Applications/Docker.app/Contents/Resources/bin:$PATH" docker compose up --build
   ```

3. Откройте [http://localhost:8000](http://localhost:8000). Для локальной анонимной заявки при пустом `BOT_TOKEN` явно установите `ALLOW_ANONYMOUS_ORDERS=true`; при подключении бота требуется подпись Telegram.
4. Панель менеджера и тарифов: [http://localhost:8000/admin](http://localhost:8000/admin), логин `admin`, пароль берётся из `.env`. Если пароль не задан, панель закрыта.

SQLite-файл хранится в `./data/orders.sqlite3` и переживает перезапуск контейнера.

## Подключение Telegram Mini App

1. Создайте бота через BotFather и добавьте его токен в `BOT_TOKEN` в `.env`.
2. Укажите публичный HTTPS-адрес этого приложения в настройке Mini App у BotFather. Для локального тестирования потребуется HTTPS-туннель.
3. Открывайте приложение кнопкой бота. При первом открытии клиентский код отправляет `Telegram.WebApp.initData`; сервер проверяет подпись токеном бота и автоматически записывает Telegram ID в таблицу `users`, даже до оформления заказа.
4. При следующем запуске тот же Telegram ID узнаётся автоматически. Для постоянного тарифа учитываются только оплаченные, выкупленные или выданные заказы; менеджер меняет статус в `/admin`.

Бот не обязан передавать ID отдельным запросом: Mini App получает подписанные данные пользователя от Telegram. Уведомления менеджеру и платежи пока не подключены.

## Курс и тарифы

- Курс Pronto, буфер, комиссии, минимумы и порог постоянного клиента редактируются в `/admin` и сохраняются в SQLite.
- `PRONTO_RATE` используется только при создании новой базы как начальное значение.
- Доставка не входит в предоплату и определяется после взвешивания в Китае.
- Курс и тарифы из ZIP-панели синхронизируются автоматически после сохранения настроек: в обоих `.env` задайте одинаковый `BOT_SETTINGS_TOKEN`, а в `legacy/poizon_app/.env` оставьте `POIZON_PICKUP_SETTINGS_URL=http://127.0.0.1:8000/api/bot/settings`. Защищённая точка интеграции принимает полный набор параметров через `PUT /api/bot/settings`. Форму настроек также можно открыть в `/admin`.

## Переменные окружения

См. `.env.example`. Перед доступом из интернета настройте `BOT_TOKEN`, сильный пароль администратора и HTTPS. Локальный контейнер привязан к `127.0.0.1`; защиту от перебора пароля и ограничение заявок также включает приложение.
